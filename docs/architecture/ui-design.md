# UI设计规范

---

## 一、设计理念

| 关键词 | 说明 |
|--------|------|
| 简洁 | 去除一切不必要的元素 |
| 清新 | 浅色背景，舒适的色彩搭配 |
| 专注 | 突出核心内容，减少干扰 |
| 友好 | 圆角设计，柔和的阴影 |

---

## 二、色彩体系

### 主色调

```
品牌主色:     #4A90D9（柔和蓝）
品牌主色-浅:  #6BA5E7（hover状态）
品牌主色-深:  #3A7BC8（按下状态）
```

### 辅助色

```
成功色: #52C41A（绿色，用于已掌握、完成状态）
警告色: #FAAD14（橙色，用于待复习）
错误色: #FF4D4F（红色，用于未掌握、错误）
信息色: #1890FF（蓝色，用于提示）
```

### 中性色

```
标题文字: #1A1A1A（黑色）
正文文字: #333333（深灰）
次要文字: #999999（浅灰）
禁用文字: #CCCCCC（更浅灰）
分割线:   #E8E8E8
背景色:   #F5F7FA（浅灰蓝）
卡片背景: #FFFFFF（白色）
```

### 单词状态语义色

```
未学习: #CCCCCC（灰色）
学习中: #1890FF（蓝色）
待复习: #FAAD14（橙色）
已掌握: #52C41A（绿色）
```

## 四、间距与圆角

### 间距

```
页面边距:     32rpx / 16px
卡片内边距:   24rpx / 16px
元素间距:     16rpx / 12px
小间距:       8rpx / 4px
```

### 圆角

```
卡片圆角:     16rpx / 12px
按钮圆角:     48rpx / 24px（胶囊按钮）
输入框圆角:   12rpx / 8px
头像圆角:     50%（圆形）
```

### 阴影

```
卡片阴影:     0 4rpx 16rpx rgba(0, 0, 0, 0.08)
弹窗阴影:     0 8rpx 32rpx rgba(0, 0, 0, 0.12)
底部导航阴影: 0 -2rpx 10rpx rgba(0, 0, 0, 0.05)
```

## 五、组件规范

### 按钮

| 类型 | 样式 | 使用场景 |
|------|------|----------|
| 主按钮 | 蓝色实心，圆角胶囊 | 主要操作（开始学习、翻译） |
| 次按钮 | 蓝色边框，白色背景 | 次要操作（换个记忆方式） |
| 文字按钮 | 蓝色文字，无边框 | 辅助操作（查看全部） |
| 禁用按钮 | 灰色背景 | 不可操作状态 |

### 卡片

| 类型 | 说明 |
|------|------|
| 内容卡片 | 白色背景，圆角12px，轻微阴影 |
| 单词卡片 | 可点击，点击后进入详情 |
| 统计卡片 | 数字突出显示，辅助说明较小 |

### 输入框

| 类型 | 说明 |
|------|------|
| 文本输入 | 圆角8px，边框#E8E8E8，聚焦时边框变蓝 |
| 语音输入 | 圆形按钮，按住录音，松开结束 |

## 六、页面结构

### APP端（4个Tab页）

```
底部导航栏:
[首页]  [单词]  [口语]  [我的]

首页:  今日学习数据、快捷入口、连续学习天数
单词:  词书选择 → 单词列表 → 单词详情 + AI速记
口语:  输入中文 → 翻译结果 + 句子拆解
我的:  个人信息、学习统计、单词本、设置
```

### 网页端布局

```
┌──────────────────────────────────────────────┐
│  Logo  [首页] [单词] [口语] [统计]   👤 [退出] │
├──────────────────────────────────────────────┤
│              主内容区域                        │
└──────────────────────────────────────────────┘
```

### 管理后台布局

```
┌──────────────────────────────────────────────┐
│  Logo                       👤 管理员 [退出]   │
├─────────┬────────────────────────────────────┤
│ 左侧菜单 │                                     │
│ ·词书   │         主内容区域                   │
│ ·单词   │                                     │
│ ·速记   │                                     │
│ ·用户   │                                     │
└─────────┴────────────────────────────────────┘
```

## 七、交互规范

### 手势操作（APP端）

| 手势 | 操作 |
|------|------|
| 左滑单词卡片 | 标记为"已掌握" |
| 右滑单词卡片 | 标记为"未掌握" |
| 下拉页面 | 刷新数据 |
| 长按单词 | 显示快捷菜单（添加到单词本、发音等） |

### 页面跳转

```
首页
├── 点击快捷入口 → 单词列表页 / 口语输入页
└── 点击最近学习 → 对应详情页

单词模块
├── 点击单词卡片 → 单词详情页
├── 点击"开始学习" → 单词学习页（卡片翻转）
└── 点击"单词本" → 我的单词本

口语模块
├── 输入文字后点击"翻译" → 翻译结果页
└── 点击历史记录 → 翻译结果页

我的页面
├── 点击"我的单词本" → 单词本列表
├── 点击"翻译历史" → 翻译历史列表
├── 点击"学习提醒" → 提醒设置
└── 点击"设置" → 设置页
```
