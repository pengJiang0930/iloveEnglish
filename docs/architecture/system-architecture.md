# 系统架构

---

## 一、架构总览

```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│   APP端     │  │   网页端     │  │  管理后台    │
│  uni-app    │  │   Vue3      │  │   Vue3      │
│   Vue3      │  │   Vite      │  │   Vite      │
└──────┬──────┘  └──────┬──────┘  └──────┬──────┘
       │                │                │
       └────────────────┼────────────────┘
                        │
                        ▼
               ┌─────────────────┐
               │     FastAPI     │
               │   (后端服务)     │
               └────────┬────────┘
                        │
        ┌───────────────┼───────────────┐
        ▼               ▼               ▼
┌─────────────┐   ┌─────────────┐   ┌─────────────┐
│    MySQL    │   │    Redis    │   │  AI服务     │
│   主数据库   │   │    缓存     │   │  OpenAI等   │
└─────────────┘   └─────────────┘   └─────────────┘
```

当前架构为**单体后端**模式，后续可按业务拆分为微服务。后端目录结构已按模块化组织：

```
server/
├── app/
│   ├── api/          # API路由层（按模块分文件）
│   ├── core/         # 核心配置（config, database）
│   ├── models/       # SQLAlchemy ORM 模型
│   ├── schemas/      # Pydantic 请求/响应模型
│   ├── services/     # 业务逻辑层
│   └── utils/        # 工具类（auth等）
├── alembic/          # 数据库迁移
└── main.py           # 应用入口
```

## 三、接口规范

### 3.1 统一返回结构

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

- `code=0` 表示成功，非0表示失败
- `message` 为提示信息
- `data` 为返回数据（可为 null）

### 3.2 认证方式

所有需要认证的接口使用 `Authorization: Bearer <token>` 请求头。

### 3.3 接口规范

- RESTful 风格
- 根路径前缀 `/api`
- 自动生成 Swagger 文档：`/docs`

## 五、数据存储

### 5.1 MySQL — 主数据库
- 编码：utf8mb4
- 数据库名：`ilove_english`
- ORM：SQLAlchemy 2.0 async
- 迁移：Alembic（迁移文件在 `server/alembic/versions/`）

### 5.2 Redis — 缓存（规划中）
- 用户会话缓存
- 热门单词缓存
- 学习统计数据缓存
- AI速记内容缓存

### 5.3 对象存储（规划中）
- 用户头像
- 词书封面
- 单词发音音频

## 六、开发环境

| 项目 | 端口 | 技术栈 |
|------|------|--------|
| 后端服务 | 8000 | FastAPI + Python 3.10+ |
| 网页端 | 3000 | Vue3 + Vite |
| APP端 | HBuilderX | uni-app + Vue3 |
| MySQL | 3306 | MySQL 8.0 |
| Redis | 6379 | Redis 7.0 |

**后端启动命令**：
```bash
cd server
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

**网页端启动命令**：
```bash
cd web
npm run dev
```

## 七、技术风险与应对

| 风险 | 应对方案 |
|------|---------|
| AI接口不稳定 | 多模型备选，实现降级策略 |
| AI响应慢 | 异步处理，缓存常用结果 |
| 数据量大 | 合理索引，定期归档 |
| 并发高 | Redis缓存，限流降级 |
