# 产品概述

> **核心原则**：简单、简单、还是简单
> **两大功能**：AI速记单词 + 日常口语转英语

---

## 一、产品定位

**一句话描述**：用最简单的方式，让你在日常生活中学会英语。

**产品理念**：
- 不搞复杂的功能堆砌
- 不搞花哨的课程体系
- 只做两件事，但做到极致

---

## 二、目标用户

| 用户群体 | 典型场景 |
|---------|---------|
| 学生群体 | 四六级/考研/留学备考，日常英语提升 |
| 职场人士 | 商务沟通，职场晋升，国际业务 |
| 英语爱好者 | 兴趣学习，旅游准备，影视爱好者 |

---

## 三、功能模块（仅两个）

### 3.1 AI速记单词

传统背单词 = 枯燥、记不住、坚持不下去
我们的背单词 = **AI帮你用"人话"记**

核心流程：选择词书 → 浏览单词列表 → 点击单词查看AI速记 → 加入单词本 → 复习巩固

### 3.2 日常口语转英语

传统学英语 = 背课文、学语法、做题
我们学英语 = **把你想说的话变成英语**

核心流程：输入中文 → AI翻译成英文 → 句子拆解（单词+语法） → 点击生词加入单词本

---

## 四、差异化优势

| 对比项 | 传统背单词APP | 我们的产品 |
|--------|--------------|-----------|
| 记忆方式 | 词根词缀、例句 | **AI生成通俗易懂的速记** |
| 学习场景 | 只能背单词 | **背单词 + 把日常用语变英语** |
| 学习闭环 | 背了就忘 | **日常使用中巩固单词** |
| 用户体验 | 枯燥、机械 | **有趣、接地气** |

**核心卖点**：
1. **AI速记**：用"人话"帮你记单词，不是学术解释
2. **场景化学习**：把你说的话变成英语，在用中学
3. **闭环**：口语中学到的生词 → 加入单词本 → 背单词巩固

---

## 五、用户流程

### 背单词流程
```
打开APP → 进入"单词"模块 → 选择词书 → 浏览单词列表
→ 点击某个单词 → 查看详情和AI速记 → 觉得有用就加入单词本
→ 继续下一个单词
```

### 口语转英语流程
```
打开APP → 进入"口语"模块 → 输入/语音说出中文
→ AI翻译成英文 → 查看句子拆解（单词、语法）
→ 点击陌生单词 → 加入单词本
```

### 复习流程
```
打开APP → 进入"我的" → 查看"我的单词本"
→ 开始复习 → 卡片模式/测试模式 → 完成复习
```
