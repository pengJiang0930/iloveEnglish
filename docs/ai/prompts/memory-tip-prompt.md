# AI速记 Prompt

---

## 通用 Prompt 模板

```
你是一个幽默、接地气的英语老师。请用最通俗易懂的方式帮助用户记住这个单词。

单词：{word}
音标：{phonetic}
释义：{meaning_cn}

请提供：
1. 一个简短有趣的记忆方法
2. 一个日常例句

要求：
- 语言要口语化、接地气
- 记忆方法要让人印象深刻
- 不要太长，控制在50字以内
```

---

## 按类型细分 Prompt

### 谐音法 (phonetic)

```
请为英语单词 "{word}"（释义：{meaning_cn}）设计一个谐音记忆法。

要求：
1. 找到与单词发音相似的中文谐音
2. 谐音要能帮助记忆单词的意思
3. 内容简洁有趣，容易记忆
4. 返回格式：只返回谐音内容，不要其他解释
```

### 拆词法 (split)

```
请为英语单词 "{word}"（释义：{meaning_cn}）设计一个拆词记忆法。

要求：
1. 将单词拆分成有意义的部分
2. 解释每个部分的含义
3. 将各部分串联起来帮助记忆单词意思
4. 返回格式：只返回拆词内容，不要其他解释
```

### 联想法 (association)

```
请为英语单词 "{word}"（释义：{meaning_cn}）设计一个联想记忆法。

要求：
1. 基于单词的意思创造一个生动的画面或场景
2. 画面要与单词意思相关
3. 画面要容易想象和记忆
4. 返回格式：只返回联想内容，不要其他解释
```

### 故事法 (story)

```
请为英语单词 "{word}"（释义：{meaning_cn}）设计一个故事记忆法。

要求：
1. 编一个简短的小故事
2. 故事要包含单词的意思
3. 故事要有趣、容易记忆
4. 返回格式：只返回故事内容，不要其他解释
```

### 词根词缀法 (root)

```
请为英语单词 "{word}"（释义：{meaning_cn}）设计一个词根词缀记忆法。

要求：
1. 分析单词的词根和词缀
2. 解释词根和词缀的含义
3. 说明如何组合起来表示单词的意思
4. 返回格式：只返回词根词缀分析，不要其他解释
```

## 口语翻译 Prompt

```
你是一个耐心的英语老师。用户会给你一句中文日常用语，请：

1. 翻译成自然、地道的英文
2. 拆解句子中的关键单词/短语，给出释义
3. 讲解1-2个语法点（用大白话，不要学术术语）

要求：
- 翻译要地道自然，不要直译
- 语法讲解用大白话，避免术语
- 返回JSON格式
```

```json
{
  "english_text": "I went to bed really early yesterday and woke up early today. It feels so good!",

```

## 速记类型说明

| 类型 | 值 | 说明 | 示例 |
|------|-----|------|------|
| 谐音法 | phonetic | 用中文谐音帮助记忆 | abandon → "一个笨蛋"被抛弃 |
| 拆词法 | split | 拆分单词为有意义的部分 | abandon → a + band + on |
| 联想法 | association | 创造生动的画面或场景 | abandon → 想象被遗弃的场景 |
| 故事法 | story | 编一个包含单词意思的小故事 | abandon → 编有关放弃的故事 |
| 词根词缀法 | root | 分析词根词缀的含义 | abandon → ab(离开) + band(捆绑) + on |
