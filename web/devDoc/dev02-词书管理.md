# Dev02 - 词书管理

## 目标

实现词书的增删改查功能，包括词书列表、新增词书、编辑词书、删除词书。

## 后端 API 接口

### 现有接口

- `GET /api/word-books` - 获取词书列表
- `GET /api/word-books/{id}` - 获取词书详情

### 需要新增的后端接口

- `POST /api/word-books` - 新增词书
- `PUT /api/word-books/{id}` - 编辑词书
- `DELETE /api/word-books/{id}` - 删除词书

## 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 是 | 词书名称 |
| description | string | 否 | 词书描述 |
| category | string | 是 | 分类：core/exam/daily |
| cover_image | string | 否 | 封面图片URL |
| is_free | number | 是 | 是否免费：0=付费, 1=免费 |
| sort_order | number | 否 | 排序序号 |
