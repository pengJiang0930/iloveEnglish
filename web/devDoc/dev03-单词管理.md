# Dev03 - 单词管理

## 目标

实现单词的增删改查功能，支持按词书筛选、批量导入、单个新增、编辑、删除。

## 后端 API 接口

### 现有接口

- `GET /api/words/book/{book_id}` - 获取词书单词列表
- `GET /api/words/{id}` - 获取单词详情

### 需要新增的后端接口

- `POST /api/words` - 新增单词
- `PUT /api/words/{id}` - 编辑单词
- `DELETE /api/words/{id}` - 删除单词
- `POST /api/words/batch` - 批量导入单词
- `POST /api/words/book/{book_id}/bind` - 批量绑定单词到词书

## 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| word | string | 是 | 英文单词 |
| phonetic | string | 否 | 音标 |
| meaning_cn | string | 是 | 中文释义 |
| meaning_en | string | 否 | 英文释义 |
| part_of_speech | string | 否 | 词性：n./v./adj./adv.等 |
| level | number | 否 | 难度等级：1-5 |
| example_sentence | string | 否 | 例句 |
| example_translation | string | 否 | 例句翻译 |
| audio_url | string | 否 | 发音音频URL |
