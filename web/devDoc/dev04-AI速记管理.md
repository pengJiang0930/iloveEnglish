# Dev04 - AI速记管理

## 目标

实现AI速记内容的管理功能，包括查看、审核、删除速记内容。

## 后端 API 接口

### 现有接口

- `GET /api/memory-tips/word/{word_id}` - 获取单词速记
- `GET /api/memory-tips/popular` - 获取热门速记

### 需要新增的后端接口

- `GET /api/memory-tips` - 获取速记列表（管理端）
- `PUT /api/memory-tips/{id}/approve` - 审核通过速记
- `DELETE /api/memory-tips/{id}` - 删除速记
- `GET /api/memory-tips/pending` - 获取待审核速记

## 速记类型说明

| 类型 | 说明 | 示例 |
|------|------|------|
| phonetic | 谐音法 | abandon → "一个笨蛋"被抛弃 |
| split | 拆词法 | abandon → a + band + on |
| association | 联想法 | abandon → 想象一个被遗弃的场景 |
| story | 故事法 | abandon → 编一个小故事 |
| root | 词根词缀法 | abandon → ab(离开) + band(捆绑) + on |

## 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| id | number | 速记ID |
| word_id | number | 关联单词ID |
| word | string | 单词 |
| tip_type | string | 速记类型 |
| content | string | 速记内容 |
| like_count | number | 点赞数 |
| is_official | number | 是否官方推荐 |
| status | number | 状态：0=待审核, 1=已审核 |
