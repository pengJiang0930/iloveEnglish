# Dev06 - 口语翻译

## 目标

实现口语翻译功能，用户输入中文，AI翻译成英文，支持句子拆解、语法讲解、单词添加。

## 后端 API 接口

### 需要新增的后端接口

- `POST /api/translate` - 翻译中文到英文
- `GET /api/translate/history` - 获取翻译历史
- `DELETE /api/translate/history/{id}` - 删除翻译历史
- `POST /api/translate/history/{id}/favorite` - 收藏/取消收藏

## 交互流程

### 翻译流程

1. 用户进入口语翻译入口页
2. 输入中文句子
3. 点击"翻译"按钮
4. 调用AI翻译接口
5. 显示翻译结果
6. 显示句子拆解
7. 显示语法讲解
8. 用户可以点击单词添加到单词本
9. 用户可以收藏翻译结果

### 历史记录

1. 用户进入翻译历史页
2. 显示所有翻译记录
3. 可以筛选收藏记录
4. 可以删除记录
5. 点击记录查看翻译结果
