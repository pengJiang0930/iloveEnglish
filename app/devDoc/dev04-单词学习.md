# Dev04 - 单词学习

## 目标

实现单词学习功能，用户可以学习当前词书中的单词，查看单词详情、AI速记。

## 后端 API 接口

### 现有接口

- `GET /api/words/next` - 获取下一个待学习单词
- `GET /api/words/{id}` - 获取单词详情
- `GET /api/memory-tips/word/{word_id}` - 获取单词速记
- `POST /api/memory-tips/generate` - 生成速记
- `POST /api/words/word-list` - 添加到单词本
- `PUT /api/word-books/user/progress` - 更新学习进度

## 交互流程

### 学习流程

1. 用户进入单词学习入口页
2. 显示当前词书和学习进度
3. 点击"开始学习"进入学习页
4. 显示单词卡片（默认隐藏释义）
5. 用户点击"显示释义"查看意思
6. 用户选择"认识"或"不认识"
7. 认识：进入下一个单词
8. 不认识：显示详细信息，可添加到单词本
9. 每学完一个单词，更新学习进度

### AI速记流程

1. 用户点击"查看AI速记"
2. 进入单词详情页
3. 显示已有的速记内容
4. 用户点击"换个记忆方式"
5. 调用AI生成新的速记
6. 显示新生成的速记
