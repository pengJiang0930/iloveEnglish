# Dev05 - 单词本

## 目标

实现单词本功能，用户可以查看已添加的单词，筛选、复习、管理单词。

## 后端 API 接口

### 现有接口

- `GET /api/words/word-list` - 获取用户单词本
- `GET /api/words/review` - 获取待复习单词
- `DELETE /api/words/word-list/{word_id}` - 从单词本移除
- `PUT /api/words/word-list/{word_id}/status` - 更新单词状态

## 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| word_id | number | 单词ID |
| word | string | 单词 |
| phonetic | string | 音标 |
| meaning_cn | string | 中文释义 |
| source | string | 来源：book=词书, translate=口语翻译 |
| status | number | 状态：0=未掌握, 1=已掌握 |
| review_count | number | 复习次数 |
| last_review_at | string | 上次复习时间 |
| next_review_at | string | 下次复习时间 |

## 复习逻辑

### 艾宾浩斯遗忘曲线

复习间隔：1天、2天、4天、7天、15天、30天

| 复习次数 | 间隔天数 |

## 交互流程

### 浏览单词本

1. 用户进入单词本列表页
2. 默认显示全部单词
3. 用户可以筛选状态和来源
4. 用户可以标记单词为已掌握/未掌握
5. 用户可以删除单词

### 复习单词

1. 用户点击"待复习"区域
2. 进入复习页面
3. 显示待复习单词卡片
4. 用户查看单词和释义
5. 用户选择"仍然陌生"或"已经掌握"
6. 更新单词状态和复习时间
7. 进入下一个待复习单词
