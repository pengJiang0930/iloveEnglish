# Dev02 - 首页与统计

## 目标

实现首页展示今日学习数据、快捷入口、连续学习天数等信息。

## 后端 API 接口

### 需要新增的后端接口

- `GET /api/stats/today` - 获取今日学习统计
- `GET /api/stats/streak` - 获取连续学习天数
- `GET /api/stats/recent` - 最近学习记录

## 任务清单

### 2.1 创建 API 封装

- [ ] `api/stats.ts` - 统计相关 API
  - `getTodayStats()` - 获取今日统计
  - `getStreak()` - 获取连续学习天数
  - `getRecentLearning()` - 获取最近学习记录

### 2.2 创建页面组件

- [ ] `pages/index/index.vue` - 首页

### 2.3 创建组件

- [ ] `components/StatsCard.vue` - 统计卡片组件

## 统计数据说明

### 今日学习统计

| 字段 | 说明 |
|------|------|
| word_learned | 今日从词书学习的单词数（正式学习） |
| sentence_word_count | 今日翻译句子中出现的单词数（额外接触） |
| translate_word_added | 今日从翻译中添加到单词本的单词数（陌生单词） |

### 连续学习

| 字段 | 说明 |
|------|------|
| current_streak | 当前连续天数 |
| longest_streak | 最长连续天数 |
| total_days | 总学习天数 |
