# Dev03 - 词书选择

## 目标

实现词书选择功能，用户可以浏览词书列表、查看词书详情、选择词书开始学习。

## 后端 API 接口

### 现有接口

- `GET /api/word-books` - 获取词书列表
- `GET /api/word-books/{id}` - 获取词书详情
- `GET /api/word-books/user/current` - 获取用户当前词书
- `GET /api/word-books/user/list` - 获取用户的词书列表
- `POST /api/word-books/select` - 用户选择词书

## 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| id | number | 词书ID |
| name | string | 词书名称 |
| description | string | 词书描述 |
| category | string | 分类：core/exam/daily |
| word_count | number | 单词总数 |
| cover_image | string | 封面图片 |
| is_free | number | 是否免费 |

## 交互流程

1. 用户进入词书列表页
2. 显示所有可用词书，当前使用的词书有标识
3. 用户可以按分类筛选词书
4. 用户点击词书卡片进入详情页
5. 在详情页可以查看词书信息和学习进度
6. 用户点击"开始学习"或"继续学习"进入学习页面
7. 如果是新词书，弹窗确认切换
