### 1.2 APP端

| 技术 | 选型 | 说明 |
|------|------|------|
| 框架 | uni-app + Vue3 | 一套代码多端运行 |
| 语言 | TypeScript | 类型安全 |
| UI库 | uv-ui / uView | uni-app生态UI库 |
| 状态管理 | Pinia | Vue3官方推荐 |
| 请求库 | uni.request 封装 | 统一请求处理 |
| 构建工具 | HBuilderX / Vite | 开发工具 |

### 1.3 网页端

| 技术 | 选型 | 说明 |
|------|------|------|
| 框架 | Vue3 | 渐进式框架 |
| 语言 | TypeScript | 类型安全 |
| 构建工具 | Vite | 快速构建 |
| UI库 | Element Plus / Naive UI | 成熟组件库 |
| 状态管理 | Pinia | Vue3官方推荐 |
| 请求库 | Axios | HTTP客户端 |
| 路由 | Vue Router | 官方路由 |
| 图表 | ECharts | 数据可视化 |

### 1.4 后端

| 技术 | 选型 | 说明 |
|------|------|------|
| 框架 | FastAPI | 现代高性能框架，自动API文档 |
| 语言 | Python 3.10+ | 易学易用 |
| 数据库 | MySQL 8.0 | 主数据库 |
| 缓存 | Redis | 缓存/会话 |
| ORM | SQLAlchemy 2.0 | 数据库操作 |
| 数据校验 | Pydantic V2 | 请求/响应模型 |
| 接口规范 | RESTful API | 统一接口 |
| 文档 | Swagger (自动生成) | API文档 |
| 认证 | JWT (python-jose) | 用户认证 |
| 异步 | async/await | 原生异步支持 |

### 1.5 AI服务

| 技术 | 选型 | 说明 |
|------|------|------|
| 大模型 | OpenAI API / 通义千问 / 文心一言 | AI能力 |
| 语音识别 | 阿里云ASR / 腾讯云ASR | 语音转文字 |
| 语音合成 | 阿里云TTS / 腾讯云TTS | 文字转语音 |

### 1.6 基础设施

| 技术 | 选型 | 说明 |
|------|------|------|
| 服务器 | 阿里云ECS / 腾讯云CVM | 云服务器 |
| 对象存储 | 阿里云OSS / 腾讯云COS | 文件存储 |
| CDN | 阿里云CDN / 腾讯云CDN | 静态资源加速 |
| 容器 | Docker | 应用容器化 |
| CI/CD | GitHub Actions / Jenkins | 自动部署 |
| 监控 | Prometheus + Grafana | 服务监控 |

## 五、技术风险与应对

| 风险 | 应对方案 |
|------|---------|
| AI接口不稳定 | 多模型备选，实现降级策略 |
| AI响应慢 | 异步处理，缓存常用结果 |
| 数据量大 | 分库分表，读写分离 |
| 并发高 | Redis缓存，限流降级 |
| 跨端兼容 | uni-app统一代码，充分测试 |
