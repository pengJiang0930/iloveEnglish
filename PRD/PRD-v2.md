# AI英语学习软件 PRD v2

> **核心原则**：简单、简单、还是简单  
> **两大功能**：背单词 + 日常口语转英语

---

## 一、产品定位

**一句话描述**：用最简单的方式，让你在日常生活中学会英语。

**产品理念**：
- 不搞复杂的功能堆砌
- 不搞花哨的课程体系
- 只做两件事，但做到极致

---

## 二、功能模块（仅两个）

### 2.1 模块一：AI速记单词

#### 2.1.1 核心思路
传统背单词 = 枯燥、记不住、坚持不下去  
我们的背单词 = **AI帮你用"人话"记**

#### 2.1.2 功能描述

**单词列表页**
- 展示单词列表（可按词书/主题分类）
- 每个单词卡片显示：单词、音标、中文释义
- 支持标记"已掌握"/"未掌握"
- 支持点击发音

**单词详情页（点击某个单词后）**
```
┌─────────────────────────────────┐
│  abandon                        │
│  /əˈbændən/                    │
│  v. 放弃；抛弃                  │
│  🔊 点击发音                    │
├─────────────────────────────────┤
│  📖 例句                        │
│  He abandoned his plan.         │
│  他放弃了他的计划。              │
├─────────────────────────────────┤
│  🧠 AI速记（核心亮点）           │
│                                 │
│  "a + band + on"                │
│  想象一个乐队（band）站在你身上  │
│  （on），你受不了了，只能"放弃"  │
│  （abandon）让他们走。           │
│                                 │
│  或者更简单：                    │
│  "啊！笨蛋！"→ 蠢到想放弃       │
│                                 │
│  [换个记忆方式] [👍有帮助]       │
├─────────────────────────────────┤
│  [+ 加入我的单词本]              │
└─────────────────────────────────┘
```

**AI速记的特点**：
- 用**通俗易懂、接地气**的语言解释
- 可以用**谐音、拆词、联想、故事**等多种方式
- 用户可以点"换个记忆方式"获取不同角度的记忆法
- 用户可以点"👍有帮助"反馈，帮助AI优化推荐

**我的单词本**
- 用户收藏的生词列表
- 支持复习模式（卡片翻转、选择题等）
- 显示添加时间和掌握状态

#### 2.1.3 词书分类（预置）
- 高频核心词汇（1000/2000/3000词）
- 四级词汇
- 六级词汇
- 考研词汇
- 雅思词汇
- 托福词汇
- 日常口语高频词

### 2.2 模块二：日常口语转英语

#### 2.2.1 核心思路
传统学英语 = 背课文、学语法、做题  
我们学英语 = **把你想说的话变成英语**

#### 2.2.2 功能描述

**输入页面**
```
┌─────────────────────────────────┐
│  💬 说说你今天想说什么？          │
│                                 │
│  ┌─────────────────────────┐    │
│  │ 我昨天睡得可早了，今天早 │    │
│  │ 早就醒过来了，真舒服     │    │
│  └─────────────────────────┘    │
│                                 │
│  [🎤 语音输入]  [✏️ 文字输入]    │
│                                 │
│         [翻译成英语 →]           │
└─────────────────────────────────┘
```

**翻译结果页**
```
┌─────────────────────────────────┐
│  📝 AI翻译                       │
│                                 │
│  I went to bed really early     │
│  yesterday and woke up early    │
│  today. It feels so good!       │
│                                 │
│  🔊 点击朗读                     │
├─────────────────────────────────┤
│  📚 句子拆解                     │
│                                 │
│  单词/短语：                     │
│  ┌──────────────────────────┐   │
│  │ went to bed  上床睡觉    │   │
│  │ really       真的、非常  │   │
│  │ early        早          │   │
│  │ yesterday    昨天        │   │
│  │ woke up      醒来        │   │
│  │ feels        感觉        │   │
│  │ so good      很舒服      │   │
│  └──────────────────────────┘   │
│                                 │
│  语法点：                        │
│  ┌──────────────────────────┐   │
│  │ "went to bed" 是 "go to  │   │
│  │ bed" 的过去式，表示"上床  │   │
│  │ 睡觉"这个动作。           │   │
│  │                           │   │
│  │ "woke up" 是 "wake up"   │   │
│  │ 的过去式，表示"醒来"。    │   │
│  └──────────────────────────┘   │
│                                 │
├─────────────────────────────────┤
│  📌 生词本                       │
│  点击上面的单词/短语可以          │
│  [添加到我的单词本]               │
└─────────────────────────────────┘
```

**交互细节**：
- 翻译结果中的**单词/短语可以点击**
- 点击后弹出详情卡片（和模块一的单词详情一样）
- 详情卡片中有 **[+ 加入我的单词本]** 按钮
- 语法讲解用**大白话**，不要学术术语

#### 2.2.3 历史记录
- 保存用户翻译过的句子
- 可以回顾之前学过的内容
- 支持收藏经典句子

## 四、用户流程

### 4.1 背单词流程
```
打开APP → 进入"单词"模块 → 选择词书 → 浏览单词列表 
→ 点击某个单词 → 查看详情和AI速记 → 觉得有用就加入单词本 
→ 继续下一个单词
```

### 4.2 口语转英语流程
```
打开APP → 进入"口语"模块 → 输入/语音说出中文 
→ AI翻译成英文 → 查看句子拆解（单词、语法） 
→ 点击陌生单词 → 加入单词本
```

### 4.3 复习流程
```
打开APP → 进入"我的" → 查看"我的单词本" 
→ 开始复习 → 卡片模式/测试模式 → 完成复习
```

## 五、AI能力要求

### 5.1 AI速记生成
**输入**：英文单词  
**输出**：
- 音标
- 中文释义
- 1-2个例句
- 通俗易懂的记忆方法（谐音/拆词/联想/故事）

**Prompt示例**：
```
你是一个幽默、接地气的英语老师。请用最通俗易懂的方式帮助用户记住这个单词。

单词：abandon
音标：/əˈbændən/
释义：v. 放弃；抛弃

请提供：
1. 一个简短有趣的记忆方法（可以用谐音、拆词、联想等）
2. 一个日常例句

要求：
- 语言要口语化、接地气
- 记忆方法要让人印象深刻
- 不要太长，控制在50字以内
```

### 5.2 口语翻译与教学
**输入**：中文日常用语  
**输出**：
- 英文翻译
- 单词/短语拆解（每个词的释义）
- 语法点讲解（用大白话）

**Prompt示例**：
```
你是一个耐心的英语老师。用户会给你一句中文日常用语，请：

1. 翻译成自然、地道的英文
2. 拆解句子中的关键单词/短语，给出释义
3. 讲解1-2个语法点（用大白话，不要学术术语）

用户输入：我昨天睡得可早了，今天早早就醒过来了，真舒服
```

## 九、差异化优势

| 对比项 | 传统背单词APP | 我们的产品 |
|--------|--------------|-----------|
| 记忆方式 | 词根词缀、例句 | **AI生成通俗易懂的速记** |
| 学习场景 | 只能背单词 | **背单词 + 把日常用语变英语** |
| 学习闭环 | 背了就忘 | **日常使用中巩固单词** |
| 用户体验 | 枯燥、机械 | **有趣、接地气** |

**核心卖点**：
1. **AI速记**：用"人话"帮你记单词，不是学术解释
2. **场景化学习**：把你说的话变成英语，在用中学
3. **闭环**：口语中学到的生词 → 加入单词本 → 背单词巩固
