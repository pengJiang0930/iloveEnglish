# PRD v3 - UI/UX 设计规范

> 三端设计：APP端、网页端、管理后台

---

## 一、设计风格总览

### 1.1 设计理念

| 关键词 | 说明 |
|--------|------|
| 简洁 | 去除一切不必要的元素 |
| 清新 | 浅色背景，舒适的色彩搭配 |
| 专注 | 突出核心内容，减少干扰 |
| 友好 | 圆角设计，柔和的阴影 |

### 1.2 色彩体系

#### 主色调
```
品牌主色：#4A90D9（柔和蓝）
品牌主色-浅：#6BA5E7（hover状态）
品牌主色-深：#3A7BC8（按下状态）
```

#### 辅助色
```
成功色：#52C41A（绿色，用于已掌握、完成状态）
警告色：#FAAD14（橙色，用于待复习）
错误色：#FF4D4F（红色，用于未掌握、错误）
信息色：#1890FF（蓝色，用于提示）
```

#### 中性色
```
标题文字：#1A1A1A（黑色）
正文文字：#333333（深灰）
次要文字：#999999（浅灰）
禁用文字：#CCCCCC（更浅灰）
分割线：#E8E8E8
背景色：#F5F7FA（浅灰蓝）
卡片背景：#FFFFFF（白色）
```

#### 语义色（单词状态）
```
未学习：#CCCCCC（灰色）
学习中：#1890FF（蓝色）
待复习：#FAAD14（橙色）
已掌握：#52C41A（绿色）
```

### 1.3 字体规范

#### APP端
```
标题（H1）：36rpx / 18pt，加粗
标题（H2）：32rpx / 16pt，加粗
标题（H3）：28rpx / 14pt，加粗
正文：28rpx / 14pt，常规
辅助文字：24rpx / 12pt，常规
小字：20rpx / 10pt，常规
```

#### 网页端
```
标题（H1）：28px，加粗
标题（H2）：24px，加粗
标题（H3）：20px，加粗
正文：16px，常规
辅助文字：14px，常规
小字：12px，常规
```

### 1.4 间距规范

```
页面边距：32rpx / 16px
卡片内边距：24rpx / 16px
元素间距：16rpx / 12px
小间距：8rpx / 4px
```

### 1.5 圆角规范

```
卡片圆角：16rpx / 12px
按钮圆角：48rpx / 24px（胶囊按钮）
输入框圆角：12rpx / 8px
头像圆角：50%（圆形）
```

### 1.6 阴影规范

```
卡片阴影：0 4rpx 16rpx rgba(0, 0, 0, 0.08)
弹窗阴影：0 8rpx 32rpx rgba(0, 0, 0, 0.12)
底部导航阴影：0 -2rpx 10rpx rgba(0, 0, 0, 0.05)
```

## 四、设计规范汇总

### 4.1 组件规范

#### 按钮

| 类型 | 样式 | 使用场景 |
|------|------|----------|
| 主按钮 | 蓝色实心，圆角胶囊 | 主要操作（开始学习、翻译） |
| 次按钮 | 蓝色边框，白色背景 | 次要操作（换个记忆方式） |
| 文字按钮 | 蓝色文字，无边框 | 辅助操作（查看全部） |
| 禁用按钮 | 灰色背景 | 不可操作状态 |

#### 卡片

| 类型 | 说明 |
|------|------|
| 内容卡片 | 白色背景，圆角12px，轻微阴影 |
| 单词卡片 | 可点击，点击后进入详情 |
| 统计卡片 | 数字突出显示，辅助说明较小 |

#### 输入框

| 类型 | 说明 |
|------|------|
| 文本输入 | 圆角8px，边框#E8E8E8，聚焦时边框变蓝 |
| 语音输入 | 圆形按钮，按住录音，松开结束 |

### 4.2 状态规范

| 状态 | 颜色 | 说明 |
|------|------|------|
| 默认 | #E8E8E8边框 | 默认状态 |
| 聚焦 | #4A90D9边框 | 输入框聚焦 |
| 成功 | #52C41A | 操作成功、已掌握 |
| 警告 | #FAAD14 | 待复习、需要注意 |
| 错误 | #FF4D4F | 操作失败、未掌握 |
| 禁用 | #CCCCCC | 不可操作 |

### 4.3 图标规范

使用统一的图标库（推荐 Remix Icon 或 Tabler Icons）：

| 图标 | 用途 |
|------|------|
| 🔊 | 发音 |
| ♡/❤ | 收藏 |
| ✓ | 已掌握 |
| + | 添加 |
| ← | 返回 |
| > | 进入 |
| 📖 | 单词 |
| 💬 | 口语 |
| 👤 | 我的 |
| 🏠 | 首页 |

### 5.1 整体风格Prompt

```
Design a mobile English learning app with a clean, modern, and friendly style.

Style guidelines:
- Primary color: #4A90D9 (soft blue)
- Background: #F5F7FA (light gray-blue)
- Card background: #FFFFFF with subtle shadow
- Rounded corners: 12px for cards, 24px for buttons
- Typography: Clean sans-serif font
- Minimalist design with focus on content
- Friendly and approachable feel

The app has 4 main tabs at the bottom: Home, Vocabulary, Speaking, Profile.
```

### 5.2 首页Prompt

```
Design a mobile app home screen for an English learning app.

Layout:
- Top: Greeting message "Good morning, Xiaoming 👋" with subtitle "Keep learning today!"
- Below: A statistics card showing today's learning data:
  - 3 main stats in a row: "Formal Learning: 10 words", "Extra Exposure: 5 words", "New Words: 1 word"
  - Below stats: "Sentences translated: 3" and "Study time: 25 min"
  - Progress bar showing daily goal progress (60%)
- Streak badge: "🔥 15-day streak"
- Quick action buttons: "Continue Learning" and "Say Something in English"
- Recent activity list at the bottom

Color scheme: Primary blue #4A90D9, light gray background #F5F7FA
Style: Clean, minimal, friendly
```

### 5.3 单词详情页Prompt

```
Design a word detail page for an English learning app.

Layout:
- Top: Back button and favorite button
- Center: Large word "abandon" with phonetic "/əˈbændən/" and audio button
- Word info: Part of speech (verb), meaning "give up; forsake"
- Example sentence section with English sentence and Chinese translation
- AI Memory Tip section (highlighted card):
  - A creative, easy-to-remember tip using word association
  - "a + band + on" - imagine a band standing on you, you can't take it anymore, so you "abandon" them
  - Buttons: "Try another way" and "👍 Helpful"
- Bottom: "Add to My Word List" button

Style: Clean, card-based design, focus on readability
```

### 5.4 口语翻译结果页Prompt

```
Design a translation result page for an English learning app.

Layout:
- Top: Back button, favorite button, share button
```

## 六、页面交互说明

### 6.1 页面跳转

```
首页
├── 点击"继续背单词" → 单词列表页
├── 点击"说句英语" → 口语输入页
└── 点击最近学习记录 → 对应详情页

单词模块
├── 点击单词卡片 → 单词详情页
├── 点击"开始今日学习" → 单词学习页（卡片翻转）
├── 点击"复习" → 复习页
└── 点击"单词本" → 我的单词本

口语模块
├── 输入文字后点击"翻译" → 翻译结果页
├── 点击语音按钮 → 录音 → 翻译结果页
└── 点击历史记录 → 翻译结果页

我的页面
├── 点击"我的单词本" → 单词本列表
├── 点击"翻译历史" → 翻译历史列表
├── 点击"学习提醒" → 提醒设置
└── 点击"设置" → 设置页
```

### 6.2 手势操作

| 手势 | 操作 |
|------|------|
| 左滑单词卡片 | 标记为"已掌握" |
| 右滑单词卡片 | 标记为"未掌握" |
| 下拉页面 | 刷新数据 |
| 长按单词 | 显示快捷菜单（添加到单词本、发音等） |
